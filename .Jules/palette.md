## 2024-03-24 - Interactive Div Accessibility
**Learning:** Custom `div` elements used as interactive components (like the orbCore button) require complete semantic setup to be accessible. This includes `role="button"`, `tabindex="0"`, `:focus-visible` styles, and keyboard event handlers for both `Enter` and `Space` keys to match native button behavior.
**Action:** Always use native `<button>` elements when possible. When custom `div` elements must be used for complex UI interactions, ensure the full suite of ARIA attributes, focus management, and keyboard handlers are implemented.
## 2024-03-24 - Interactive Div Accessibility
**Learning:** Custom `div` and `span` elements used as interactive components (like the file browser items or breadcrumbs) require complete semantic setup to be accessible. While `div` elements lack native keyboard support entirely, even `span` elements require `tabindex="0"` and explicit keyboard event listeners (like `onkeydown="if(event.key==='Enter'||event.key===' ') { ... }"`) to function like buttons. Furthermore, custom styles often omit or hide the default browser focus ring, making keyboard navigation invisible.
**Action:** Always prefer native `<button>` elements for interactives. When custom `span` or `div` elements must be used, explicitly add `tabindex="0"`, keyboard handlers, and ensure `:focus-visible` styles are defined to maintain keyboard visibility.
